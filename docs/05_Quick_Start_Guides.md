# DOCUFLOW AUTOMATION SYSTEM — QUICK-START GUIDES BY ROLE
**Document Version:** 2.4.0  
**Target Audience:** New Onboarding Staff, Training Managers  
**Classification:** Onboarding & Operational Quick Reference  

---

## 1. ADMINISTRATOR QUICK-START GUIDE

```
1. SIGN IN with Administrator credentials
   ↓
2. CONTROL SETTINGS -> USER MANAGEMENT -> Add New Employee
   ↓
3. CONTROL SETTINGS -> ACCESS CONTROL -> Set Role Clearance Matrix
   ↓
4. WORKFLOW & RULES -> FLOW BUILDER -> Design Approval Stages
   ↓
5. WORKFLOW & RULES -> CONDITION BUILDER -> Link Routing Rules
   ↓
6. MONITOR SYSTEM AUDIT LOGS & BACKUPS
```

---

## 2. AP EXECUTIVE (DOCUMENT INTAKE) QUICK-START GUIDE

```
1. SIGN IN with AP Executive credentials
   ↓
2. UPLOAD DOCUMENT -> Select Division & Expense Category
   ↓
3. UPLOAD PDF INVOICE -> Click Run Automated OCR Extraction
   ↓
4. VERIFY EXTRACTED FIELDS -> Gross Amount, GST, PO Number
   ↓
5. SUBMIT & QUEUE -> Document enters Stage 1 Approval Workflow
```

---

## 3. FINANCE MANAGER (APPROVER) QUICK-START GUIDE

```
1. SIGN IN with Finance Manager credentials
   ↓
2. OPEN WORK TRACKER -> Click Assigned Document Row
   ↓
3. INSPECT DATA & VERIFY MANDATORY CHECKLIST ITEMS
   ↓
4. CHOOSE ACTION:
   ├── APPROVE & PASS STAGE -> Ownership transfers to Stage 3
   ├── HOLD / PAUSE         -> Enter mandatory clarification notes
   └── REJECT DOCUMENT      -> Enter mandatory rejection notes
```

---

## 4. CUSTOMER FEEDBACK AGENT QUICK-START GUIDE

```
1. SIGN IN with Customer Feedback credentials
   ↓
2. OPEN CUSTOMER FEEDBACK -> Select "Pending Review" Tab
   ↓
3. INSPECT COMPLAINT ROW -> Review Customer Details & Evidence Photos
   ↓
4. CHECK SLA COUNTDOWN TIMER
   ↓
5. CLICK APPROVE / PASS STAGE -> Select Next Assigned Officer & Designation
   ↓
6. CONFIRM HANDOVER -> Ticket updates to Stage 2 In Progress
```
